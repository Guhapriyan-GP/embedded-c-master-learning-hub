# Stage 08: Hardware Timers & PWM Generation

## 1. Prerequisites
Stage 07 (GPIO hardware) & Stage 06 (Clock tree).

## 2. Core Technical Theory & Engineering Principles
Microcontroller hardware timers provide autonomous, high-precision timebases, pulse-width modulation (PWM), and signal timing without burdening the CPU with software delay loops.

### 1. Counter Architecture
The core of every timer comprises:
- **Prescaler Register (`PSC`):** 16-bit divisor scaling the peripheral timer clock down to counter clock ticks.
- **Counter Register (`CNT`):** 16-bit or 32-bit register incrementing or decrementing on each clock tick.
- **Auto-Reload Register (`ARR`):** Sets the counter threshold, triggering an Update Event (UEV) and resetting `CNT`.

### 3. Pulse Width Modulation (PWM) Modes
PWM is generated by continuously comparing `CNT` with the Capture/Compare Register (`CCR`):
- **PWM Mode 1:** Output is active (HIGH) while $	ext{CNT} < 	ext{CCR}$, and inactive (LOW) while $	ext{CNT} \ge 	ext{CCR}$.
- **Preload Registers (`ARPE`, `OCxPE`):** Buffers new ARR and CCR values in shadow registers, applying changes only at the next update event to prevent mid-cycle duty-cycle glitching.
