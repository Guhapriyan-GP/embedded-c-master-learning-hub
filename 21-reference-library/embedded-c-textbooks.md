# Authoritative Textbooks & Industry Engineering References

This library identifies foundational textbooks and engineering references covering computer architecture, embedded C programming, real-time operating systems, and firmware engineering.

---

### 1. Foundational Computer Science & C Programming
1. **The C Programming Language (2nd Edition)**
   - *Authors:* Brian W. Kernighan & Dennis M. Ritchie
   - *Significance:* The definitive reference for ANSI C syntax, pointer mechanics, data structures, and memory manipulation.
2. **Expert C Programming: Deep C Secrets**
   - *Author:* Peter van der Linden
   - *Significance:* In-depth breakdown of array-to-pointer decay, memory layouts, stack frames, and subtle compilation subtleties.
3. **Computer Systems: A Programmer's Perspective (3rd Edition)**
   - *Authors:* Randal E. Bryant & David R. O'Hallaron
   - *Significance:* Bridges the gap between C programming, assembly language, memory hierarchies, linker scripts, and hardware execution.

---

### 2. Embedded Systems & ARM Cortex-M Architecture
1. **The Definitive Guide to ARM Cortex-M3 and Cortex-M4 Processors (3rd Edition)**
   - *Author:* Joseph Yiu
   - *Significance:* The industry-standard reference written by an ARM senior architect; covers exception handling, NVIC priority grouping, fault diagnosis, and assembly programming.
2. **Embedded Systems with ARM Cortex-M Microcontrollers in Assembly Language and C (4th Edition)**
   - *Author:* Dr. Yifeng Zhu
   - *Significance:* Rigorous academic textbook covering hardware register manipulation, boot sequences, clock trees, and low-level peripheral drivers.
3. **Making Embedded Systems: Design Patterns for Great Software**
   - *Author:* Elecia White
   - *Significance:* Practical embedded architecture, state machines, interrupt servicing, memory budgeting, and hardware abstraction patterns.
4. **Embedded Systems: Real-Time Operating Systems for ARM Cortex-M Microcontrollers**
   - *Author:* Jonathan W. Valvano
   - *Significance:* Deep exploration of concurrency, thread scheduling, priority inversion, and real-time digital interfacing.
