# Capstone Projects Overview

The projects in this directory integrate multiple peripheral engines and firmware concepts into complete, standalone embedded systems.

| Project Directory | Title | Complexity | Key Technologies |
|---|---|---|---|
| [`01-beginner-smart-instrument-panel/`](01-beginner-smart-instrument-panel/README.md) | **Smart Instrument Panel** | Beginner to Intermediate | GPIO, SysTick, TIM2 PWM, EXTI interrupts, USART telemetry |
| [`02-intermediate-dma-data-logger/`](02-intermediate-dma-data-logger/README.md) | **High-Speed DMA Data Logger** | Intermediate | ADC multichannel scan, Circular DMA, I2C OLED display, Flash memory ring buffer |
| [`03-advanced-freertos-digital-power-controller/`](03-advanced-freertos-digital-power-controller/README.md) | **Digital Power & Motor Controller** | Advanced / Production | FreeRTOS, Preemptive task queues, Mutexes, High-resolution PWM, Overcurrent fault protection, Watchdogs |
