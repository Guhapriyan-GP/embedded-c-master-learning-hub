# Pending External Hardware Connections & Bench Verification Schedule

> **Target Board:** ST **NUCLEO-G474RE** (`MB1367 Rev C`, `STM32G474RET6`, `VDD = 3.3 V` nominal / `3.28 V` measured)  
> **Scope:** Consolidated master schedule of **ALL** experiments, drivers, capstone peripherals, and bench-instrument measurements that were intentionally deferred during zero-wire onboard validation and require physical external components, jumper wires, or test instruments.  
> **Global Electrical Safety Rules (NON-NEGOTIABLE):**
> 1. **Voltage Limit:** Supply external logic strictly from **`3.3 V` (`CN6 Pin 4` / `CN7 Pin 16`)** — NEVER apply `5.0 V` to non-FT analog pins (`PA0`, `PA1`, `PA4`, `PB0`)! Check DS12288 Table 12 (`FT` vs `FT_a` / `TT_a`) before wiring any signal.
> 2. **Current Limit:** Limit per-GPIO pin current to `<= 8 mA` continuous (always use `330 Ω`–`1 kΩ` series resistors on LEDs).
> 3. **Power Measurement Jumper:** Use **`JP6` (`IDD`)** ONLY for microamp/milliamp MCU current profiling — **NEVER remove `JP5` (`PWR` source selector)** while measuring `IDD`!
> 4. **`PB8-BOOT0` Warning:** NEVER pull `PB8` HIGH at reset unless intentionally entering ST System Memory Bootloader (`I2C1` in this repository is routed to **`PA15`/`PB7`** specifically to avoid `PB8-BOOT0`).
> 5. **Power Off Before Wiring:** Disconnect USB (`CN1`) before adding or removing breadboard wires, jumpers, or external power stages.

## 4. Reusable Driver Library External Checks (`23-code-library/Drivers/`)

Out of the **12 reusable drivers** in `23-code-library/Drivers/`, **10 drivers** (`clock_g4`, `gpio_g4`, `usart_g4`, `ring_buffer`, `tim_g4`, `exti_g4`, `adc_g4`, `dma_g4`, `iwdg_g4`, `fault_handler`) have been **physically exercised on NUCLEO-G474RE silicon**, plus `i2c_g4`'s bounded absent-slave `NACKF` path. The remaining external-wire driver checks are:
1. **`spi_g4.c` (`SPI1` `PB3`/`PB4`/`PB5`):** Connect `PB4 <-> PB5` loopback jumper (or external 3.3 V SPI slave) and run `spi_init_master()` + `spi_transfer_buf()` across Modes 0–3.
2. **`i2c_g4.c` (`I2C1` `PA15`/`PB7`):** Connect an external 3.3 V I2C slave (e.g., SSD1306 `0x3C` or EEPROM `0x50`) with `4.7 kΩ` pull-ups to verify `i2c_write()`, `i2c_read_reg()` Repeated START, and `i2c_recover_bus_9clks()`.
3. **`clock_g4.c` (`Clock_Init_170MHz_HSE24()`):** Optional bench check of the onboard `24 MHz` HSE crystal `X3` (`MB1367 Rev C`) + MCO `PA8` frequency counter check (`±50 ppm` vs `±1%` HSI16).
