# Curriculum Mastery Assessments

This directory provides five comprehensive written and practical examinations. A student or learner must pass each assessment with at least an 85% score before proceeding past the corresponding phase of the curriculum.

| Assessment File | Targeted Stages | Key Competencies Tested |
|---|---|---|
| [`stage-01-c-mastery-exam.md`](stage-01-c-mastery-exam.md) | Stage 01 | Binary representation, pointer arithmetic, struct alignment, bitmasking, operator precedence. |
| [`stage-02-embedded-c-register-exam.md`](stage-02-embedded-c-register-exam.md) | Stage 02 & 03 | Memory-mapped I/O, volatile semantics, RMW hazards, ARM Cortex-M4 registers, stack frame tracing. |
| [`stage-03-arm-cortex-m-architecture-exam.md`](stage-03-arm-cortex-m-architecture-exam.md) | Stage 04 & 05 | Linker scripts (`.text`, `.data`, `.bss`), startup sequence, vector table relocation, STM32 bus matrix. |
| [`stage-04-stm32-peripherals-exam.md`](stage-04-stm32-peripherals-exam.md) | Stages 06 - 12 | Clock tree PLL math, Flash wait states, GPIO BSRR, Timers PWM math, UART baud divisors, ADC sampling, DMA circular buffers. |
| [`stage-05-rtos-and-advanced-firmware-exam.md`](stage-05-rtos-and-advanced-firmware-exam.md) | Stages 13 - 16 | FreeRTOS task scheduling, priority inversion, mutexes, ISR queues, watchdogs, low-power states, MISRA C. |
