**Target Silicon:** **STM32G474RET6** (LQFP64 package, ARM Cortex-M4F r0p1, 170 MHz, 512 KB Dual-Bank Flash, 128 KB SRAM: 80 KB SRAM1 + 16 KB SRAM2 + 32 KB CCM-SRAM)  
**Target Evaluation Board:** **NUCLEO-G474RE** (**MB1367 Rev C**, STLINK-V3E onboard probe)  
**Primary CMSIS Ground Truth Verified:** [`23-code-library/Drivers/CMSIS/Device/ST/STM32G4xx/Include/stm32g474xx.h`](../23-code-library/Drivers/CMSIS/Device/ST/STM32G4xx/Include/stm32g474xx.h) (`__CM4_REV = 0x0001U`, `__MPU_PRESENT = 1U`, `__NVIC_PRIO_BITS = 4U`, `__FPU_PRESENT = 1U`, max external IRQ = `FMAC_IRQn = 101`)

## 1. Silicon Die vs. LQFP64 Package Boundary (Explicit `NOT_APPLICABLE` Table)

A foundational hardware distinction verified against **DS12288 Table 2** and **`stm32g474xx.h`** is the boundary between peripherals declared in the shared CMSIS device header (covering LQFP48 through LQFP128/UFBGA121) versus peripherals physically bonded out and usable on the **LQFP64 `STM32G474RET6`**:

| Peripheral / Feature | Concept ID | Silicon / CMSIS Header Status (`stm32g474xx.h`) | Physical LQFP64 Status (`STM32G474RET6`) | Classification | Mandatory Curriculum Guidance |
|---|---|---|---|---|---|
| **AES / CRYP / HASH** | `G4-AES-001` | **0 definitions** in `stm32g474xx.h`; **IRQ 85 reserved/absent** | **Non-existent on STM32G474 silicon** (present only on STM32G483/STM32G484) | `NOT_APPLICABLE` | Use hardware `RNG` (`0x50060800`) + `CRC` (`0x40023000`) + software crypto (mbedTLS/TinyCrypt/Monocypher) + Flash `RDP`/`SEC1R`. |
| **FMC / FSMC Parallel Bus** | `G4-FMC-001` | Present in die header (`FMC_Bank1_R` `0xA0000000`, `FMC_IRQn = 48`, `RCC_AHB3ENR_FMCEN`) | **Unbonded on LQFP64** (external parallel bus requires $\ge 100$-pin package per DS12288 Table 2) | `NOT_APPLICABLE` | Document silicon-vs-package boundary; use `QUADSPI` (`0x90000000` XIP, Bank 1 pins available on LQFP64) for external memory. |
| **GPIOE & SPI4 External I/O** | `G4-SPI4-001` | Present in die header (`GPIOE` `0x48001000`, `SPI4` `0x40013C00`, `SPI4_IRQn = 84`) | **0 Port E pins bonded on LQFP64**; all `SPI4` AF pins reside on Port E | `NOT_APPLICABLE` | Exactly **52 GPIOs** exist on LQFP64 (`PA0–15`, `PB0–15`, `PC0–15`, `PD2`, `PF0–1`, `PG10-NRST`) and **3 external SPIs** (`SPI1`, `SPI2/I2S2`, `SPI3/I2S3`). |
| **ARMv8-M TrustZone-M** | `ARM-SEC-002` | Absent (`ARMv7E-M` Cortex-M4 r0p1) | **Single security state** (no `SAU`/`IDAU`/`SG`/`MSPLIM`) | `NOT_APPLICABLE` | Use Cortex-M4 privilege separation (`CONTROL.nPRIV`, 8-region MPU, `SVC`) + STM32G4 Flash `RDP`/`WRP`/`PCROP`/`SEC1R`. |
