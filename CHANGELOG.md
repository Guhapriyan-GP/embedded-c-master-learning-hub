# Changelog

All notable technical updates, module additions, and curriculum releases are documented in this file.

---

### [v1.0.0] - Initial Production Release
- **Curriculum Architecture:** Complete 16-stage sequential learning curriculum covering C fundamentals to advanced FreeRTOS concurrency.
- **Hardware Targeting:** Complete register maps, base addresses, and peripheral drivers for the STM32G474RET6 (ARM Cortex-M4 @ 170 MHz).
- **Practical Laboratories:** 15 reproducible hands-on bare-metal laboratory experiments for the NUCLEO-G474RE board.
- **Capstone Projects:** 3 end-to-end practical projects (Smart Instrument Panel, DMA Data Logger, FreeRTOS Digital Controller).
- **Video Research Database:** 50 individually verified educational video lectures mapped across all curriculum stages with full metadata.
- **Reference Library:** Complete bibliography covering official ST documentation (RM0440, DS12288, PM0214), ARM manuals, textbooks, and standards.
- **Technical Diagrams:** Full Mermaid architecture diagrams for bus matrix, clock tree, memory map, interrupt flow, and comprehensive register maps.
- **Code Templates:** Verified buildable bare-metal template with Makefile, linker script, startup code, and CMSIS headers.
- **Mastery Assessments:** 5 comprehensive examinations with theory questions and practical coding challenges.
